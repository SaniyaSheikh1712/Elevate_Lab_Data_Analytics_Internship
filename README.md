# Elevate Lab  Task 1: Data Cleaning and Preprocessing

## Objective

The objective of this project is to clean and prepare a raw dataset by handling missing values, duplicate records, inconsistent text formats, column names, and data types.

## Tools Used

* Python
* Pandas
* Google Colab

## Data Cleaning Steps

1. Loaded the raw dataset.
2. Identified missing values.
3. Handled missing values.
4. Identified and removed duplicate records.
5. Standardized text values.
6. Cleaned and standardized column names.
7. Checked and corrected data types where required.
8. Saved the final cleaned dataset.


## Conclusion

The dataset was successfully cleaned and preprocessed. Missing values and duplicate records were handled, text formatting was standardized, column names were cleaned, and data types were checked. The final dataset is ready for further analysis or visualization.
