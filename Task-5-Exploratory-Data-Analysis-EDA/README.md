# Task 5 – Exploratory Data Analysis (EDA)

## Objective
Performed Exploratory Data Analysis on the Titanic dataset to identify patterns, relationships, distributions, and factors affecting passenger survival.

## Work Performed
- Loaded the Titanic dataset using Seaborn.
- Inspected dataset shape, columns, data types, and basic statistics.
- Checked and handled missing values.
- Performed statistical analysis.
- Analyzed overall survival distribution.
- Compared survival rates by gender.
- Compared survival rates by passenger class.
- Analyzed age and fare distributions.
- Created histograms for Age and Fare.
- Created boxplots to identify outliers.
- Detected Fare outliers using the IQR method.
- Created an Age vs Fare scatter plot.
- Created a Pairplot for numerical variables.
- Created a Correlation Heatmap.
- Calculated survival rates by gender and passenger class.
- Identified important factors related to passenger survival.
- Documented key findings and conclusions.

## Key Findings
- Female passengers had a significantly higher survival rate than male passengers.
- First-class passengers had the highest survival rate.
- Third-class passengers had the lowest survival rate.
- Fare contained several outliers.
- Age and Fare did not show a strong linear relationship.
- Gender and passenger class were important factors associated with survival.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.
